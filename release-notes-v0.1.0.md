# fb2-to-epub v0.1.0 — первый релиз 🎉

Первая упакованная версия: теперь это **приложение для macOS в `.dmg`**. Раньше установка шла только через терминал — сейчас достаточно скачать, перетащить и выбрать папку. Дальше всё происходит само.

## Что это

Кидаешь в выбранную папку книги в формате **FB2** — рядом появляются готовые **EPUB**. Никаких ручных запусков: приложение следит за папкой в фоне и конвертирует новые файлы автоматически.

- Понимает отдельные файлы `.fb2`, архивы `.fb2.zip` и целые папки с книгами (с любой вложенностью).
- Исходники не трогает, уже сконвертированное не делает заново.
- **Обложки:** берёт встроенную из книги; если её нет — ищет подходящую онлайн; нет интернета — собирает EPUB без обложки.
- Конвертацию выполняет проверенный движок **Calibre**.

## Установка

1. Скачай файл **`fb2-to-epub-0.1.0.dmg`** ниже (раздел Assets).
2. Открой его и **перетащи приложение fb2-to-epub в папку «Программы»** (Applications) — стрелка на фоне окна подскажет куда.
3. Запусти приложение. Оно проверит, что установлен Calibre, и предложит **выбрать папку** для книг (по умолчанию создаёт `~/Desktop/fb2-to-epub`).

Готово. Теперь просто складывай книги в эту папку.

## Первый запуск (важно)

Приложение собрано без платной подписи Apple, поэтому при **первом** открытии macOS попросит подтверждение. Это разовый шаг — дальше приложение запускается обычным двойным кликом.

- **Правый клик** на `fb2-to-epub` в папке «Программы» → **«Открыть»** → в диалоге ещё раз **«Открыть»**.
- *Либо:* запусти приложение, затем зайди в **Системные настройки → Конфиденциальность и безопасность** и нажми **«Открыть всё равно»**.

> Если выбрал папку внутри **Рабочего стола, Документов или Загрузок** и конвертация не запускается — выдай приложению **Полный доступ к диску** (Full Disk Access) в Системных настройках. Подробная инструкция — в [README](https://github.com/ArrivaRUS/fb2-to-epub#full-disk-access-если-папка-в-desktop--documents--downloads).

## Требования

- **macOS 11.0** или новее.
- **[Calibre](https://calibre-ebook.com/download_osx)** — `brew install --cask calibre` или скачать с сайта. Если его нет, приложение само предложит открыть страницу загрузки.
- **python3** — входит в Xcode Command Line Tools: `xcode-select --install`. Нужен только для поиска обложек.

## Для тех, кто любит терминал

Есть и продвинутый путь установки — без DMG, тем же установщиком:

```sh
brew install --cask calibre
git clone https://github.com/ArrivaRUS/fb2-to-epub.git
cd fb2-to-epub
./install.sh
```

Подробности и команды управления — в [README](https://github.com/ArrivaRUS/fb2-to-epub#readme).
