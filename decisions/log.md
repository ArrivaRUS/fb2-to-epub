## 2026-07-22 — Боевой тест 1.0.0: дыра CJM «Full Disk Access» → фича v1.0.1

### D46. FDA-онбординг — полный паттерн (детект → карточка → ведение за руку)
- **Контекст:** боевая проверка человека: движок установился, агент «работает» (зелёный),
  но книги на Desktop молча не конвертируются — фоновому агенту не выдан Full Disk Access
  (TCC-зона; на новом Маке гранты не переезжают). Пользователю НЕОТКУДА узнать: всё выглядит
  работающим. FDA жил только пассивной строкой в Настройках и абзацем README.
- **Решение (человек, выбор из 2):** полный онбординг-паттерн по образцу движка:
  (1) агент сам детектит отказ доступа к папке при старте (EPERM ≠ пустая папка) и пишет
  флаг в state.json; (2) приложение показывает заметную карточку/блокер «Нет доступа к папке»
  + шаг в Setup сразу после движка; (3) кнопка открывает точную панель системных настроек
  И кладёт путь раннера в буфер обмена + шаги 1-2-3; (4) «Проверить снова» пинает агента.
  Выдать FDA программно невозможно (ограничение macOS) — автоматизируем всё остальное.
- **Почему:** класс «выглядит работающим, но молчит» — худший UX; ровно его закрывал
  онбординг движка. Паттерны/токены готовы — дизайн-раунд не нужен.
- **Гейт:** явный заказ человека («надо в CJM, активное действие, желательно за него») +
  выбор объёма. Релиз v1.0.1 — своя СТОП-точка.

## 2026-07-19 — Онбординг Calibre: архитектура (G4, суд двух архитекторов)

### D40. Закрытие окна не прерывает установку
- **Контекст:** развилка архитекторов — Claude: диалог «Прервать/Продолжить» (закрытие = отмена); Codex: загрузка продолжается в фоне.
- **Решение:** подход Codex — закрытие окна НЕ прерывает: приложение живёт в Dock, загрузка идёт, повторное открытие показывает прогресс, Cmd-Q предлагает отмену; во время copy/promote выход откладывается до безопасной зачистки.
- **Почему:** «нажал установить и свернул» — естественный сценарий для 330 МБ; InstallStore и так живёт в AppDelegate. Цена — динамическая terminate-policy (`applicationShouldTerminateAfterLastWindowClosed`).
- **Гейт:** G4, явное «да» человека.

### D41. Пре-чек диска 1,5 ГБ + текст «нужно ~1 ГБ»
- **Решение:** до скачивания проверяем ≥1,5 ГБ на томе App Support; текст в UI «~1 ГБ» (реальный пик ~1,1 ГБ: DMG 330 МБ + распакованный движок ~700–800 МБ). Макеты правятся (раунд 2 из 2, было «~500 МБ»).
- **Почему:** честный отказ ДО скачивания дешевле ошибки «нет места» посередине.
- **Гейт:** G4, «да» человека.

### D42. macOS 11–13 — автоустановки нет, сразу «Вручную»
- **Контекст:** наш минимум macOS 11.0 (build-app.sh:26), свежий Calibre требует macOS 14+. Альтернатива — пиннутые легаси-DMG (7.26/6.29).
- **Решение:** на macOS < 14 автоустановка честно отключена → экран «Установить вручную» (сайт предлагает совместимые версии сам). Легаси-веток не строим.
- **Почему:** человек выбрал меньше кода и тестовой поверхности; аудитория утилиты — свежие маки. Пересмотреть, если появятся жалобы пользователей старых ОС.
- **Гейт:** G4, «да» человека.
- **Общий контекст суда:** синтез `arch/plan-calibre-onboarding-synthesis.md` — каркас #1 (Claude: CalibreLocator+parity, CalibreInstaller, EngineSetupCard, оживление через installer.sh), находки #2 (Codex: cover-finder на env EBOOK_META, сырая история для блокер/баннер, agentActivationFailed ≠ провал установки, codesign/LSMinimumSystemVersion-проверки, hardcode-тест). Отброшено: transaction-journal, homebrew-кандидаты, 6-state RuntimeHealth, renameatx_np, смена didShowSetup.

## 2026-07-19 — Онбординг Calibre: кнопка автоустановки (G2b)

### D37. Подача на Status — гибрид A+B
- **Контекст:** после переезда на новый Mac Calibre отсутствует → агент молча не работает; единственный сигнал — тусклая строка в Настройках. UX-Analyst подготовил 2 направления: A (баннер-карточка, история видна) и B (полноэкранный блокер на кольце).
- **Решение:** гибрид — блокер B, когда истории конвертаций нет (первый запуск / пустой переезд); баннер A, когда история есть.
- **Почему:** блокер максимально заметен там, где пользователю нечего терять из виду; баннер не прячет книги у «переехавших». Чистые A или B отвергнуты как компромисс в одну сторону.
- **Гейт:** G2b, явное «да» человека (выбор из 3 опций).
- **Последствия:** экраны Status/Setup ветвятся по `calibreInstalled()`; бейдж агента при отсутствии движка честный («Конвертация недоступна»). Артефакты: `design/calibre-onboarding/{flow.md,direction-A-banner.html,direction-B-blocker.html}`, `research/calibre-auto-install.md`.

### D38. Кнопка — «Установить Calibre» (+ подпись «движок конвертации»)
- **Решение:** главный CTA называет бренд движка, подпись объясняет простым языком.
- **Почему:** прозрачность (что именно ставим) + узнаваемость при поиске ошибок; «Установить движок» отвергнут как менее честный.
- **Гейт:** G2b, «да» человека.

### D39. Calibre ставим в папку приложения, не в /Applications
- **Решение:** автоустановка кладёт `calibre.app` в `~/Library/Application Support/fb2-to-epub/`.
- **Почему:** без пароля админа, без TCC «App Management» при будущих обновлениях; GUI Calibre нам не нужен — только CLI (`ebook-convert`/`ebook-meta`/`ebook-polish`). `/Applications` отвергнут (пароль + трение при апдейтах). Ресёрч: официальный DMG стабилен (`calibre-ebook.com/dist/osx` → GitHub releases, universal, ~330 МБ), подписан+нотаризован, SHA-512 публикуется, quarantine при скачивании не-браузером не ставится.
- **Гейт:** G2b, «да» человека.
- **Последствия:** D3 (2026-06-23, «детект + подсказка») эволюционирует в «детект + автоустановка»; красная линия GPL — НЕ бандлить бинари Calibre в наш дистрибутив — остаётся в силе.

## 2026-06-23 — Продуктовизация: бренд + DMG + установщик

### Контекст (находки, не решения)

### D1. Приложение = одноразовый установщик
**Решение:** не резидентный меню-бар-апп, а одноразовый установщик: запуск → выбор папки → настройка launchd-автоматизации на этот путь → закрытие. Дальше всё работает фоном.

### D2. Дистрибуция без подписи (бесплатно)
**Решение:** DMG без платной подписи Apple; первый запуск — через честный обход Gatekeeper без денег (ПКМ→Открыть / снятие quarantine / инструкция).
**Почему:** человек выбрал бесплатный путь ($0 vs $99/год Apple Developer). Подпись+нотаризацию можно добавить позже как апгрейд UX. Необратимых трат нет.

### D3. Calibre — внешняя зависимость (детект + подсказка) [дефолт]
**Решение (дефолт Юрки, человек не возразил):** Calibre остаётся внешней зависимостью; приложение детектит его и при отсутствии подсказывает установку (Homebrew cask / сайт). Встраивание движка в приложение — НЕ делаем для v1.
**Почему:** встроить Calibre = сотни МБ + сложность + нюансы GPL; несоразмерно для v1. Пересмотреть, если понадобится «zero-dependency».

## 2026-06-23 — Синтез архитектуры (G4) + дефолт папки

## 2026-06-25 — Нативный UI приложения (фаза дизайна, G2b)

### D9. Эволюция D1: апплет → нативное окно «установка + статус»
**Решение:** заменить AppleScript-апплет нативным окном (форма — «установка + статус», тот же визуальный язык что у образца + бренд fb2-to-epub). Логика конвертации (watcher+Calibre+launchd) НЕ меняется — только UI-слой.
**Почему:** AppleScript умеет лишь системные диалоги, их нельзя стилизовать под образец; для нужного уровня нужен нативный UI. Расширяет D1 (был «одноразовый установщик») до окна со статусом — человек выбрал объём «установка + статус», не полный дашборд.

### D10. Отслеживание включено по умолчанию (нет кнопки «Старт»)
**Решение:** на первом запуске приложение сразу отслеживает `~/Desktop/fb2-to-epub` (Calibre permitting); кнопки «Начать отслеживание» нет, папку можно сменить. Геро-кольцо — **статусное** (активно/конвертирую/пауза), без абстрактных процентов.
**Почему:** человек: «по умолчанию отслеживание должно работать»; процент в кольце бессмыслен для конвертера.

### D11. Очередь выбора обложки (новая фича)
**Решение:** если в книге нет встроенной обложки и онлайн найдено **2+** подходящих кандидата → ставим лучшую **сразу (не блокируя конвертацию)** и кладём книгу в очередь **«Выбрать обложку»** в окне; пользователь выбирает из превью → epub переобрабатывается. Показ — **только очередью в окне** (без живых поп-апов). Если найдена одна/ноль — авто как сейчас.
**Почему:** конвертация фоновая и автоматическая — блокирующий поп-ап завис бы, когда человека нет у компа; очередь-в-окне никогда не блокирует. Выбор «2+ / только очередь» — явный выбор человека. Требует расширения движка: `cover-finder` → топ-N кандидатов + превью, файловая очередь в App Support, переобработка обложки в epub (Calibre).
