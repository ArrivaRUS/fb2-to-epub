## Проект
Утилита **fb2-to-epub** — авто-конвертация FB2 → EPUB на macOS по выбранной папке. Фоновый launchd-агент (watcher + Calibre) + нативное SwiftUI-приложение (Status / Настройки / Выбор обложки / Setup).
- Код: `/Users/arrivarus/Documents/VibeCoding2/2026.06 fb2-to-epub` (git, ветка `main`).
- GitHub: [ArrivaRUS/fb2-to-epub](https://github.com/ArrivaRUS/fb2-to-epub) — **PUBLIC**.
- **Последний релиз v1.0.3:** https://github.com/ArrivaRUS/fb2-to-epub/releases/tag/v1.0.3 (DMG sha `b9fba0bd`). Цепочка v1.0.0 → v1.0.1 (FDA-онбординг) → v1.0.2 (бинарный раннер, Tahoe-фикс) → v1.0.3 (самолечение настройки агента). Память проекта — в этой папке (decisions/.patches/arch/design), НЕ под Юркой; **untracked, в публичный репо НЕ идёт** (в git только README/код/скриншоты).

## Архитектура (контракт)
- **D13:** приложение ТОЛЬКО читает `state.json` (владелец — агент, атомарно tmp→rename); приложение использует app-owned маркеры в `state/`, в `state.json` НЕ пишет. Обложки вшивает агент (ebook-polish).
- Маркеры приложения в `state/`: `stats-baseline`, `today-baseline` (date-aware, истекает при смене дня), `recent-cleared-at`. Сброс статистики пишет все три.
- `state.json` содержит `batch{active,total,done}` (прогресс пачки → кольцо). `covers/queue/<id>.json` — кандидаты обложки + `best_candidate_id` + `confident` (title-match).
- Пути: watch `~/Desktop/fb2-to-epub`; данные `~/Library/Application Support/fb2-to-epub/{state,covers/{queue,previews,jobs,generated},bin}`. Шаблоны обложек — в бандле `Contents/Resources/cover-templates/`.
- Сборка: `xcrun swiftc` arm64+x86_64 → lipo → ad-hoc codesign (ретрай против FinderInfo-гонки iCloud). `build/build-app.sh <ver>` + `make-dmg.sh <ver>` (копирует cover-templates). ⛔ `runner.sh` не трогать (грант FDA по байтам).
- Env-вспомогалки: `FB2_FORCE_COVER/SETTINGS/SETUP` · `FB2_FORCE_BATCH="done/total"` · `FB2_GENCOVER_TEST="author|title|out-dir"` · `FB2_COVERS_DIR` · `FB2_STATE_DIR`(агент; приложение state.json читает реальный) · `FB2_BUNDLED_RES_DIR` · `FB2_SKIP_KICKSTART`.
