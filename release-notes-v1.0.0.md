# fb2-to-epub v1.0.0 — работает из коробки 🎉

_Релиз от 2026-07-22 · macOS 11 и новее_

Веха 1.0 — приложение наконец **работает из коробки**.

Раньше конвертация запускалась, только если на Mac **уже стоял Calibre** — движок, который делает всю работу. Не стоял — приложение молча ничего не конвертировало, и разбираться приходилось самому. Теперь оно **ставит движок само**: увидело, что Calibre нет, показало кнопку, скачало, проверило, установило и запустило. Скачал приложение, перетащил — и всё: дальше по одной кнопке, без терминала и без пароля администратора.

## ✨ Что нового

**Автоустановка Calibre — по одной кнопке.**
Если движка нет, приложение показывает кнопку **«Установить Calibre»**. Дальше всё само:
- скачивает Calibre с официального сайта (~330 МБ) — **с полосой прогресса и кнопкой «Отмена»**;
- проверяет, что файл целый и настоящий (контрольная сумма SHA-512 и цифровая подпись);
- ставит движок в **собственную папку приложения** — **без пароля администратора и без лишних подтверждений**;
- сам запускает фоновый агент — и конвертация оживает.

**Честные экраны, когда движка ещё нет.**
Больше никакого «молчит и не работает» — приложение прямо говорит, что конвертировать пока нечем, и ведёт к установке:
- на **первом запуске** — крупная подсказка с отдельным шагом **«Движок»**;
- если книги уже конвертировались раньше (например, после переезда на новый Mac) — аккуратная карточка над историей, книги остаются на виду;
- статус агента честно показывает **«Конвертация недоступна»** янтарным цветом;
- строка-действие есть и в **Настройках**.

**Установку можно свернуть.**
Нажал «Установить» и закрыл окно — **загрузка продолжится в фоне**. Приложение живёт в Dock; откроешь заново — увидишь живой прогресс. Выход через **⌘Q во время установки** вежливо переспросит, чтобы ты не оборвал загрузку случайно.

**Ручная установка — для старых систем.**
Если автоустановка недоступна (см. «Требования»), приложение показывает **три коротких шага** и кнопку **«Проверить снова»**: поставил Calibre руками, нажал — и приложение подхватит движок **без перезапуска**.

**Заработало главное меню приложения.**
Теперь работают привычные сочетания: **⌘Q** (с умным вопросом во время установки), а также **⌘C / ⌘V / ⌘A** — в том числе в полях **Автор** и **Название** на экране выбора обложки.

## 🔧 Что изменилось

- **Требования к системе.** Автоустановка работает на **macOS 14 и новее**. На более старых версиях автоустановки нет — приложение покажет **ручную установку с подсказками**.
- **Если Calibre уже установлен** в папке «Программы» — используется он, ничего не скачивается.
- **Удаление** (`uninstall.sh`) теперь убирает и **собственную копию движка**, которую поставило приложение.

## 🐛 Что починили

- **Сбой на середине установки больше не оставляет тебя без движка.** Если что-то прервалось в момент замены — рабочий Calibre не теряется.
- **⌘Q снова закрывает приложение.** Раньше в сборке приложение могло «тихо» выйти мимо диалога — теперь выход во время установки честно спрашивает подтверждение.

## Требования

- **macOS 14.0** или новее — для автоустановки Calibre по кнопке.
  На **macOS 11–13** приложение работает, но Calibre нужно поставить **вручную** (приложение подскажет как).
- Если **Calibre уже установлен** — подойдёт любая совместимая версия, качать ничего не надо.
- **python3** (входит в Xcode Command Line Tools: `xcode-select --install`) — нужен только для поиска обложек.

## Как обновиться и поставить

- **Уже пользуешься приложением:** открой **⚙ Настройки → «Проверить обновление»** — оно само скачает и поставит 1.0.0.
- **Ставишь впервые:** скачай `.dmg` ниже (раздел Assets), перетащи приложение в «Программы» и запусти. При первом открытии macOS попросит подтверждение (приложение без платной подписи Apple) — это разовый шаг: **правый клик** по приложению → **«Открыть»** → в диалоге ещё раз **«Открыть»**.

## Breaking changes

**Нет.** Обновление ничего не ломает: если Calibre у тебя уже стоит — всё работает как прежде; если нет — появится кнопка, которая его поставит. Отдельная миграция не нужна.

## Под капотом (одной строкой)

Онбординг покрыт шестью наборами автотестов (поиск движка, паритет, страж хардкода, установщик, сквозной e2e, UI-фикстура), а живой сквозной прогон с настоящим скачиванием Calibre пройден.
