## Решения человека
- **Вариант A** — поля Название/Автор **всегда открыты** (не карандаш). Заголовок карточки
  книги заменяется двумя редактируемыми полями.
- **Показывать строку «было: <исходник>»** под изменённым полем (зачёркнутый оригинал).
- **Ноту «Обложка в файле не найдена — выбери из найденных» УБРАТЬ** — её место занимает
  хинт про правку (ниже). (Если для не-confident книг важно объяснить «почему я тут» —
  это ловим на visual-verify; по умолчанию нота убрана.)

## Раскладка (в `bookCard`, ~app/CoverSelectView.swift:939–990)
Вместо статичного Text-заголовка (Название · Автор) — блок из двух полей, ВЫШЕ строки
имени файла. Порядок сверху вниз: [Поле Название] [Поле Автор] [хинт-строка] [строка файла].

## Токены (намерение; сверить с Tokens.swift)
- **Поле:** фон `C.inputBg` (≈#0E0B16); бордер `C.fieldBorder` (white ~.08) 1px; радиус 8;
  паддинги ~6/10/7 (t/side/b); вертикальный gap между полями ~7.
- **Капс-подпись поля** («НАЗВАНИЕ»/«АВТОР»): `F.cap` (9px bold), `Track.cap`, `C.textTertiary`,
  uppercase, margin-bottom 3.
- **Инпут Название:** типографика `CS.bookTitle` (15px bold), `Track.h1`, `C.textPrimary`.
- **Инпут Автор:** `CS.bookAuthor` (14px medium), `C.textSecondary`.
- **Плейсхолдер:** `C.textVeryMute`, regular.
- **Фокус:** бордер → `C.accentOrange` @~.55 + halo (box-shadow 2px accentOrange@~.14);
  капс-подпись → `C.accentOrange`.
- **Изменено (значение ≠ исходного, непустое):** бордер → `C.emerald` @~.28; капс-подпись →
  `C.emerald`; точка 5×5 `C.emerald` со свечением слева от подписи; строка **«было: <исходник>»**
  — ~9.5px mono, `C.textVeryMute`, оригинал зачёркнут (при длинном — обрезать по ширине).
- **Хинт-строка** (заменяет ноту «не найдена»): иконка `info.circle` 12 + текст `CS.bookNote`
  (11px), `C.textTertiary`, gap 6, margin-top ~9 (`CS.bookNoteTop`); слова «Поправь на русский» —
  `C.textSoft`. Текст по умолчанию: «Данные из файла. Поправь на русский, если распозналось
  неверно — текст попадёт на обложку и в метаданные.»

## Поведение (связка с M4)
- Поля предзаполнены из `entry.title`/`entry.author`; правка пишет в `edits[bookId]`
  (`MetaEdit`), питает `effTitle`/`effAuthor`.
- Правка (debounce ~400 мс) → сброс `generated[bookId]` → `kickGenerated()` (превью
  перерисовываются по eff-значениям).
- `onResearch` («Искать ещё») берёт hint из eff-значений.
- `edits[bookId]` НЕ сбрасывать при `finishResearch` (R5).
- Реальная редактируемость/фокус — проверить КЛИКОМ/вводом на verify (не только рендер;
  урок gui-verify-interaction-not-render).
