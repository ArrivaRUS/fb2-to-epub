## 1. Правило гибрида (какую подачу рендерит Status)

```
!calibreInstalled() && historyEmpty  → БЛОКЕР B (вместо контента Status)
!calibreInstalled() && !historyEmpty → БАННЕР A (карточка под шапкой, контент виден)
calibreInstalled()                   → обычный Status (фича невидима)
```
`historyEmpty` — по СЫРОМУ snapshot watcher: `converted_total == 0 && recent пуст &&
last_conversion == nil` (НЕ по отфильтрованному `loadState()` — «Сбросить статистику»
не должен превращать баннер в блокер; решение суда, из плана Codex).
Внутри выбранной подачи состояния установки (downloading/installing/success/error/manual)
идут по одной машине (`flow.md` §3); подача не переключается посреди процесса.

## 5. Setup — честный первый запуск (общий)

- Приветствие: «Почти готово» (вместо «Готово к работе»); подзаголовок: «Осталось
  поставить движок конвертации — кнопка ниже, дальше всё само.»
- Шаг «ДВИЖОК»: янтарный (`step-cur`-стиль: тинт `C.stepCurBg`, номер accentOrange),
  label «Calibre не найден», sub «Нужен для конвертации»; в теле шага —
  `[Установить Calibre]` cta-sm КРУПНАЯ + «Вручную» link-btn.
- Шаг «ПАПКА» («ОТСЛЕЖИВАЕМАЯ ПАПКА») — зелёный как сейчас, с [Сменить…].
- Футер: foot-dot warn + «Ожидает движок».
- После установки шаг зелёный «Calibre X.Y найден · Готов к конвертации», приветствие
  «Готово к работе», футер «Отслеживание активно» (= текущее поведение).

## 6. Инварианты подач и анимаций

- Окно 400px (`M.windowWidth`), тёмная тема безусловно; других брейкпоинтов нет.
- Никакого авто-скачивания без явного тапа (flow.md §10.1 — заложено, ждёт подтверждения
  человека на G3; поведение по умолчанию = только по тапу).
- Высота окна: появление/уход баннера/блокера — через штатный `present`/refit
  (уроки .patches/011/013: без in-view identity swap; проверить min/max контент).
- Кольцо B наследует урок .patches/014: round-cap/градиент без шва на старте.
- Анимации: `.prog.indet` slide 1.15s ease-in-out; спиннер installing 1.1s linear;
  success-glow статичен (без пульса).
- Тексты — строго из таблиц выше и flow.md §6; слово «Calibre» только на кнопках/подписях,
  объяснения — словами «движок конвертации».

## 7. Чеклист поэлементной сверки (для DesignReviewer / visual-verify)

По каждому реализованному экрану против refs/*.png: (1) геометрия баннера/блокера
(margins/padding/radius по tokens.md §1/§4); (2) цвет фона/бордера варианта
(warn/err/ok — точные rgba); (3) шрифты заголовка/подтекста (размер/вес/lh);
(4) прогресс-бар 6px/r3 + mono-подпись + bold-% (tabular); (5) кольцо: диаметр 104,
штрих 8, состояние (пунктир/арк/спиннер/полное) и центр-иконка (SF Symbol + размер);
(6) CTA: градиент, паддинги своего варианта (крупная/компактная), тень; (7) бейдж
агента и foot-dot; (8) тексты 1-в-1;
(9) состояния строки Настроек; (10) янтарный шаг Setup. ≥1 несовпадение = FAIL.
