# Запасные обложки FB2 → EPUB — типографские шаблоны (концепты)

4 шаблона книжной обложки на случай, когда обложка не найдена в интернете и собирается
скриптом (без генеративного ИИ): только векторная типографика + цвет/формы.
Концепты на согласование — финал после выбора человека.

- **Формат:** портрет 2:3, `viewBox="0 0 1200 1800"`, SVG-вектор.
- **Зоны текста:** в каждом SVG помечены комментарием `{author}` и `{title}`.
- **Пример (короткий):** «Алексей Варламов» / «Падчевары».
- **Пример (длинный):** «Фёдор Достоевский» / «Война и мир. Том первый» — файлы `*-long.svg`.

## Палитра и шрифты по шаблонам
1. **Минимализм** — фон `#F4F1EA`, чернила `#1A1A1A`, акцент `#B0492E`. Hoefler Text + Gill Sans.
2. **Классика** — фон `#F6EFE0`, тёмно-коричневый `#3A2E1E`, золото `#8A6D3B`. Georgia italic (название) + Baskerville (автор).
3. **Модерн** — фон `#FAFAF7`, графит `#1D1D1D`, красный `#E63946`. Helvetica Neue Bold.
4. **Тёмный** — фон `#0E0E14`, акцент `#F59E42`, текст `#F5F0E6`/`#C9C2B4`. Cochin + Gill Sans.
   (акцент/фон совпадают со стилем приложения fb2-to-epub.)

## Правила тяги/переноса текста (для будущего скрипта)
Общий принцип: текстовая зона имеет «целевой кегль» и «минимальный кегль». Скрипт
сначала пробует уместить в одну строку при целевом кегле; если ширина строки превышает
рабочее поле — переносит по словам и ступенчато уменьшает кегль до минимального.

- **Минимализм / Классика / Тёмный (центрированные):** `{title}` — 1 строка → при
  переполнении 2–3 центрированные строки, кегль ступенями (базовый **166** у минимализма,
  **177** у классики и тёмного — укрупнён под маленькие экраны читалок; далее вниз ~116 → 92).
  При переносе межстрочный интервал берётся **пропорционально кеглю (~1.15–1.18×)**, не
  фиксированным px, иначе строки наезжают; блок названия центрируется по вертикали.
  `{author}` — 1 строка (кегль ~**60-69**, метки ~**39-45**); при длинном имени сначала
  сжимается межбуквенный интервал (до 2px), затем кегль, в крайнем случае 2 строки.
  **NB (узкая рамка классики):** базовый кегль названия 177 держит только короткие слова
  (~9-10 узких букв; «Падчевары» ок). Замерено: «Воскресение» влезает при ≤150,
  «Преступление» при ≤130. Для классики порог уменьшения/переноса наступает РАНЬШЕ — скрипт
  обязан мерить ширину строки, а не только число строк. (Открытый вопрос к человеку: оставить
  базовый 177 с ранним авто-уменьшением длинных или сделать базовый классики чуть меньше.)
- **Модерн (левое выравнивание, верхний регистр):** `{title}` — стопка строк по словам
  сверху вниз (шаг ~0.92–0.95em), кегль ступенями (~200 → 112), последняя строка не должна
  заходить за диагональ (держать y нижней строки выше линии раздела). `{author}` — в
  светлой плашке, ширина плашки = ширина текста + поля; длинное имя уменьшает кегль.
- Везде следить за минимальной читаемостью; при экстремально длинном тексте допускается
  обрезка с многоточием на уровне скрипта (правило согласовать с человеком).

## Рендер — важное (см. `.patches/012`)
Под cairosvg на macOS кириллицу корректно рендерят: **Georgia, Times New Roman,
Baskerville, Palatino, Hoefler Text, Cochin** (serif); **Gill Sans, Helvetica,
Helvetica Neue, Arial** (sans). **Didot, Futura, Avenir дают tofu (квадраты) — не использовать.**
Все 4 шаблона и их длинные версии проверены фактическим SVG→PNG с кириллицей.
В `font-family` всегда заложен серверный fallback-стек.

**Отдельно:** `Baskerville` в **italic** рендерит строчную «ы» как «ъı» (баг cairosvg) —
курсивную антикву для кириллицы брать из **Georgia italic** (в шаблоне 2 так и сделано),
Baskerville использовать только в прямом начертании. Baskerville/Hoefler/Cochin/Gill Sans —
это `.ttc`, но конкретно эти рендерятся корректно (проверять каждый шрифт И начертание).
