# 017 — NSSupportsSuddenTermination из бойлерплейта отрезал весь terminate-lifecycle

**Дата:** 2026-07-22 · **Фича:** онбординг Calibre (D40) · **Нашёл:** live-verify Юрки → debugger (A/B)

## Что случилось
Диалог D40 «Установка движка ещё идёт» (Cmd-Q во время скачивания) не появлялся никогда:
приложение выходило мгновенно и молча. Код делегата был правильный. Причина — в шаблоне
Info.plist внутри `build/build-app.sh` с САМОГО ПЕРВОГО коммита нативного UI (4691e55) лежал
бойлерплейт-ключ `NSSupportsSuddenTermination = true`: с ним AppKit на `terminate:` /
quit-AppleEvent завершает процесс через `exit()`, вообще не вызывая
`applicationShouldTerminate`. Заодно `NSSupportsAutomaticTermination = true` позволял системе
убивать приложение без окон — прямо против обещания D40 «закрыл окно — установка живёт».

## Почему не поймали раньше
- Юнит-тесты дергают методы делегата напрямую — обход происходит ДО делегата, на уровне AppKit.
- Cmd-Q «не работал всегда», но до D40 это никого не волновало: выход шёл через закрытие окна.
- Сборка/ревью видят ключи как «стандартный plist-шаблон» — никто не спрашивал, зачем они.

## Как нашли
Только живой рукой на реальном бинаре (live-verify), затем debugger с A/B: один бинарь,
переключён один plist-ключ — противоположное поведение (runA: смерть без входа в делегат;
runB: вход + алерт).

## Правило на будущее
1. **Каждый ключ Info.plist — осознанное решение, не бойлерплейт.** Копируешь шаблон —
   объясни в комментарии каждый нетривиальный ключ или удали его.
2. **Делегатные lifecycle-пути (terminate/reopen/last-window-closed) проверяются ТОЛЬКО живым
   бинарём.** Юнит на метод делегата ничего не говорит о том, будет ли метод вообще вызван.
3. Страж: grep-тест на запрещённые ключи (`NSSupportsSuddenTermination`,
   `NSSupportsAutomaticTermination`) в `tests/run-calibre-hardcode-grep.sh` (кейсы 9–10).
4. Верификационная готча: синтетический `cmd+q` (CGEvent) может не матчиться при русской
   раскладке — для проверки шортката жми ПУНКТ МЕНЮ (тот же код-путь) или физическую клавиатуру.
